# Crypto Scanner

Приложение для macOS: скринер токенов в 10 сетях, скам-проверка контрактов, оценка риска и расчёт уровней входа и выхода по твоим правилам.

## Установка

1. Открой [последний релиз](../../releases/latest) и скачай `CryptoScanner.dmg`.
2. Открой файл и перетащи **Crypto Scanner** в папку «Программы».
3. Первый запуск: в «Программах» нажми на приложение правой кнопкой → **Открыть** → **Открыть**. Это нужно один раз, потому что приложение не подписано платным сертификатом Apple.
   Если macOS всё равно не даёт открыть: **Системные настройки → Конфиденциальность и безопасность** → внизу кнопка **«Всё равно открыть»**.

Обновление: скачай новый `.dmg` из релизов и замени приложение в «Программах». Настройки и ключи сохраняются.

## Что внутри

| Раздел | Что делает |
| --- | --- |
| Скринер | Ищет токены по стратегиям-пресетам с уровнем риска, автоматически проверяет контракты |
| Проверка токена | Полный разбор любого токена по адресу контракта |
| Мои правила | Стоп-лосс, тейк-профиты и размер позиции для каждой категории риска |
| Сильные кошельки | Следующий этап |
| Копи-трейдинг | Следующий этап |

Сети: Solana, Ethereum, BNB Chain, Base, Arbitrum, Polygon, Avalanche, Optimism, Sonic, HyperEVM.

Источники данных: DexScreener (рынок), GoPlus Security (контракты). Приложение не хранит приватные ключи и не проводит сделки: кнопка «Открыть на DexScreener» ведёт на пару, сделку ты подтверждаешь в своём кошельке.

## Разработка

Swift Package, SwiftUI, macOS 14+. Сборка `.app` и `.dmg` выполняется в GitHub Actions при каждом push в `main` (`scripts/package.sh`).
